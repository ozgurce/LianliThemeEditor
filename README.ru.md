# Lian Li LCD Theme Editor

**Языки:** [English](README.en.md) | [Русский](README.ru.md)

Неофициальный редактор LCD-шаблонов для Lian Li L-Connect 3.

Редактор предназначен для устройств Hydroshift II LCD и позволяет просматривать, редактировать, добавлять, перемещать, предварительно просматривать и применять слои LCD-шаблонов без ручного редактирования каждого элемента в L-Connect.

> Проект не связан с Lian Li, не является официальным приложением и не поддерживается Lian Li. Перед изменением важных тем сохраняйте резервные копии.

## Возможности

- Редактирование существующих LCD-шаблонов L-Connect 3.
- Поддержка Hydroshift II LCD-S и Hydroshift II LCD-C.
- Автоматический fallback, если активный шаблон относится к другому семейству устройства.
- Квадратный предпросмотр для LCD-S и круглая маска предпросмотра для LCD-C.
- Предпросмотр текста, данных, изображений, графиков, GIF и MP4.
- Загрузка и применение фоновых GIF/MP4.
- Таблица слоев с типом, источником данных, текстом, медиа, позицией, размером, шрифтом, жирностью, цветом и форматом.
- Добавление текстовых слоев.
- Добавление live data слоев: CPU/GPU temperature, load, clocks, fan/pump data, time, date и day.
- Добавление изображений.
- Добавление graph/bar слоев из modular styles L-Connect.
- Редактирование graph style, позиции, размера, цветов и источника данных там, где это поддерживается.
- Перемещение слоев вверх/вниз для управления порядком отрисовки.
- Добавление и отслеживание shadow layers.
- Поддержка прозрачных цветов через ARGB/hex значения.
- Форматы даты и времени, например `Y-M-D`, `D-M-Y`, `D.M.Y`, `00:00`, `00:00:00`.
- Интерфейс на английском, турецком, русском и упрощенном китайском.
- Темная и светлая тема интерфейса.
- `Apply All` для сохранения изменений и обновления L-Connect без перезапуска сервиса управления вентиляторами.

## Установка

1. Откройте страницу релизов:
   <https://github.com/ozgurce/LianliThemeEditor/releases>
2. Скачайте `EXE.zip`.
3. Распакуйте архив.
4. Структура после распаковки должна быть такой:

```text
ThemeEditor.exe
supporter.exe
lang/
  en.json
  ru.json
  tr.json
  zh.json
```

5. Запустите `ThemeEditor.exe`.

## Требования

- Windows 10 или Windows 11.
- Установленный L-Connect 3.
- Права администратора рекомендуются для записи в `C:\ProgramData\Lian-Li\L-Connect 3`.
- `ffmpeg` рекомендуется для более надежной работы с видео/GIF.

## Быстрое использование

1. Откройте L-Connect 3 и выберите LCD-устройство.
2. Выберите template в L-Connect или оставьте активный template.
3. Запустите `ThemeEditor.exe`.
4. Выберите тип устройства:
   - `Hydroshift II LCD-S`
   - `Hydroshift II LCD-C`
5. Оставьте `Use active template` включенным или введите Template ID вручную.
6. Нажмите `Load`.
7. Выберите слой в таблице или на предпросмотре.
8. Измените позицию, шрифт, источник данных, текст, размер, цвет, формат или параметры графика.
9. Нажмите `Apply` для выбранного слоя.
10. Используйте `Apply All`, чтобы сохранить изменения и обновить L-Connect.

## Устранение проблем

### Access denied

Запустите приложение от имени администратора. L-Connect хранит шаблоны в `C:\ProgramData`, и для записи туда могут требоваться повышенные права.

### Фон применился, но предпросмотр показывает другое медиа

Проверьте custom background в профиле L-Connect. Приложение фильтрует custom background paths по выбранной модели устройства, потому что некоторые template ID существуют и для LCD-S, и для LCD-C.

### Неверный язык, тема или устройство при запуске

Используйте последнюю версию релиза. В версии `0.985` исправлена проблема, при которой programmatic selection при запуске мог менять сохраненные preferences.

## Отказ от ответственности

Используйте на свой риск. Всегда сохраняйте резервные копии перед редактированием L-Connect templates. Не перезапускайте сервисы L-Connect без необходимости, так как они могут быть связаны с управлением вентиляторами и помпой.
